# SATS-PI

Recevez des sats du monde, dépensez des FCFA chez vous.
Pont entre Bitcoin Lightning et PI-SPI (BCEAO), pour les paiements vers mobile money.

Une seule base de code web, trois livrables :
- Web / PWA : apps/web
- Android (APK) : apps/mobile (Capacitor, enveloppe le build de apps/web)
- Ordinateur (Windows, Linux, macOS) : apps/desktop (Tauri, enveloppe le build de apps/web)
- API : backend (FastAPI)

Démarrage rapide : voir docs/architecture.md et scripts/dev.sh
